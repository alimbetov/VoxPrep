## P0-1 — deterministic Flutter dependencies (required before CI acceptance)

From a checkout of the PR branch, using the Flutter SDK version pinned by this repository:

```bash
cd mobile/careerspeak_app
flutter --version
flutter pub get
git diff -- pubspec.lock
# Confirm url_launcher and its resolved platform packages exist with actual pub.dev checksums.
git add pubspec.lock

flutter pub get --enforce-lockfile
git diff --exit-code -- pubspec.yaml pubspec.lock
```

**PASS only if:** committed `pubspec.lock` contains the resolved `url_launcher` packages and hashes generated by pub; the locked resolution succeeds on a fresh runner. Never synthesize checksum values. Run Flutter Main and Mock UI CI on the resulting SHA, not on the previous green commit.

## P0-2 — real Content Studio browser acceptance

Environment: PostgreSQL with latest Liquibase changes; Backend with `VOXPREP_MEDIA_EXTERNAL_VIDEO_ENABLED=true`; valid admin session. Use a disposable unpublished lesson and a curated public YouTube URL. Record browser/platform, timestamp, content type, revision IDs and screenshots or capture paths.

1. Author a DRAFT Vocabulary lesson with cover image, content image, and Piper/Kokoro audio binding. Attach the YouTube URL/title through the actual Content Studio form. **PASS:** accepted; all pre-existing image/audio associations unchanged.
2. Reload the editor. **PASS:** canonical video metadata persists, form remains usable, title is escaped.
3. Publish via the normal workflow; query learner endpoint using matching FREE entitlement. **PASS:** exact CURRENT revision returns correct video ID/title with HTTP 200 and `Cache-Control: no-store`. For content with no video expect 204.
4. Try to update/remove the published video through the admin browser with a valid CSRF token. **PASS:** 409, snapshot unchanged. Attempt direct SQL UPDATE/DELETE on snapshot as a controlled DB test; **PASS:** blocked by trigger.
5. Create next DRAFT revision and change video. **PASS:** original published revision remains unchanged; no draft link leaks through learner API.
6. Test a FULL lesson under FREE entitlement, a user without admin permissions, CSRF failure, and `VOXPREP_MEDIA_EXTERNAL_VIDEO_ENABLED=false`. **PASS:** no unauthorized video metadata; flag-disabled learner route returns no video.
7. Reopen lesson in offline Flutter mode. **PASS:** existing images, MP3, learner completion and Drift content still work. Video need not be available offline.

Do not mark this gate PASS from MVC integration tests alone.

2. Tap the explicit external video action once. **PASS:** exact validated HTTPS YouTube URL launches by user action only (browser or supported YouTube app); no in-app WebView/autoplay.
